## Getting Started with Vyvern

### Frontend Setup
1. Navigate to the `vyvern-frontend` directory.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Backend Setup
1. Navigate to the `vyvern-backend` directory.
2. Start the server:
   ```bash
   node server.js
   ```

---

Enjoy working with Vyvern!
